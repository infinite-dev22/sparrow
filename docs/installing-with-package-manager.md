## Installation With Package Manager

sparrow is available in below software repositories:

[![Packaging status](https://repology.org/badge/vertical-allrepos/sparrow.svg)](https://repology.org/project/sparrow/versions)

sparrow is also additionally available via:

- [Flatpak](https://flathub.org/apps/details/dev.sparrow.sparrow)
- [Scoop](https://scoop.sh/#/apps?q=sparrow)


For Fedora Linux, sparrow is (unofficially) available via dnf RPM package manager, using nightly as of 2024.01:

- [copr](https://copr.fedorainfracloud.org/coprs/titaniumtown/sparrow/)

```bash
sudo dnf copr enable titaniumtown/sparrow 
sudo dnf install sparrow
```
