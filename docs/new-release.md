# Updating versioning for package managers and whatnot

- App metainfo: `extra/linux/dev.sparrow.sparrow.metainfo.xml`
- macOS plist (`CFBundleShortVersionString`): `extra/macos/sparrow.app/Contents/Info.plist`
- Rust: `Cargo.toml`
- Obviously changelog: `CHANGELOG.md`
- RPM spec: `sparrow.spec`
- Windows wix spec (`<Product [...] Version=X.X.X>`): `extra/windows/wix/sparrow.wxs`
